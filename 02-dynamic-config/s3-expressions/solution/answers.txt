## 9. 변수 우선순위
예측: qa → lookup 결과 t3.micro
terraform output instance_type   # "t3.micro"

우선순위 (낮음 → 높음)
기본값 < TF_VAR_env(dev) < terraform.tfvars(stg) < *.auto.tfvars(prod) < -var / -var-file(qa)

하나씩 제거하며 확인
- -var-file=qa.tfvars 제거      → env=prod → "t3.small"
- prod.auto.tfvars 삭제         → env=stg  → "t3.micro"
- terraform.tfvars 삭제         → env=dev  → "t3.micro"
- unset TF_VAR_env              → 기본값 dev → "t3.micro"
(stg/dev는 instance_type 출력이 같으므로 terraform console에서 var.env로 확인한다)

정리: rm terraform.tfvars prod.auto.tfvars qa.tfvars; unset TF_VAR_env
